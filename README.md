# Adya Residence — Hikkaduwa

A responsive, single-page website for Adya Residence, featuring its two modern studio apartments, amenities, short- and long-stay information, and direct WhatsApp booking links.

## Run locally

Open `index.html` in a browser. The site uses plain HTML, CSS, and JavaScript with no build step.

## Customize

- Replace the sample Unsplash photography in `index.html` with approved property images.
- Update copy or location details as needed; the exact property address is not included on the site.
- WhatsApp booking links use `+94 77 033 3223`.
